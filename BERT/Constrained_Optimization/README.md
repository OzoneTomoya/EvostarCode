# Merge Quant (BERT Models, Constrained Optimization)

Experiments on constrained optimization with BERT models.

## Environment Setup
1. If the `FT_Model.zip` file has not been extracted, extract it.
```
unzip ../FT_Model.zip -d ..
```

2. Create a virtual environment
```
python -m venv [envname]
```

3. Activate the virtual environment
```
source [envname]/bin/activate
```

4. Install the required libraries
```
pip install -r requirements.txt
```

5. (Optional) Log in to Hugging Face

Some gated or restricted models may require requesting access on Hugging Face before downloading.

```
huggingface-cli login
```

## Running the Experiment
1. Run the script
```
bash ./optimization.sh
```

## optimization.sh
The following example is intended for a quick functionality check.  
For full experiments, increase the value of `--num-trials`.
```
python main.py \
    --optimization Sequential_MergeParameter \
    --num-trials 5 \
    --seed-cmaes 0 \
    --seed-merge 0 \
    --wandb False \
    --wandb-project 'MergeQuant' \
    --num-save-trials 100 \
    --result-dir 'results' \
    --figure-dir 'figures' \
    --test-best True \
    --create-graph True \
    --target-bit 6 \
```
- optimization: Optimization strategy
    - `Sequential_MergeParameter`: Optimizes merge parameters
    - `Sequential_BitWidth`: Optimizes quantization bit-widths
        - To run this, the file `./config/best_config_seed{args.seed-cmaes}.yml` is required. This file is generated by running `Sequential_MergeParameter` with the same seed.
    - `Joint`: Optimizes merge parameters and quantization bit-widths
- num-trials: Number of Optuna trials
- seed-cmaes: Random seed for the sampler
- seed-merge: Random seed for model merging
- wandb: Enable experiment logging with Weights & Biases (optional) (`True` or `False`)
- wandb-project: Project name used when logging experiments with Weights & Biases (W&B)
- num-save-trials: Interval for saving intermediate results
- result-dir: Directory to save results
- figure-dir: Directory to save figures
- test-best: Evaluate the best configuration on the test set
- create-graph: Generate optimization history plots
- target-bit: Target average bit-width for quantization

## Experimental Results

The raw experimental results and optimization logs are stored in the `result/` directory. Results are organized by optimization strategy and random seed.

For clarity and reproducibility, this repository stores experimental results in a more organized format than the original implementation.
As a result, some saved files may differ slightly from those used during the original experiments.

### Directory Structure
```
result/
├── Joint/
│   ├── seed=0/
│   │   ├── results_seed=0/
│   │   └── figure_seed=0/
│   ├── seed=1/
│   ├── seed=2/
│   ├── seed=3/
│   └── seed=4/
├── Sequential_MergeParameter/
│   ├── seed0/
│   │   ├── results_seed=0/
│   │   └── figure_seed=0/
│   ├── seed=1/
│   ├── seed=2/
│   ├── seed=3/
│   └── seed=4/
└── Sequential_BitWidth/
    ├── seed0/
    │   ├── results_seed=0/
    │   └── figure_seed=0/
│   ├── seed=1/
│   ├── seed=2/
│   ├── seed=3/
│   └── seed=4/
```

- `results`
    ```
    results/
    ├── best_config.yml      # Merge parameters corresponding to the best performance during optimization
    ├── best_bit.yml         # Quantization bit-widths corresponding to the best performance during optimization
    ├── best_score.json      # Final score using the best configuration and bit-widths
    ├── tmetrics.json        # Final score obtained using the best configuration and bit-widths
    ├── study_trials.csv     # Optimization history (all trials)
    └── tmetrics_{num}.json  # Evaluation results saved at each interval during optimization (only trials satisfying the constraints are counted)
    ```

- `figures`
    ```
    figures/
    └── optimization.png   # Progression of the best score during optimization
    ```
