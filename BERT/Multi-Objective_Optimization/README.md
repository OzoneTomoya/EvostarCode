# Merge Quant (BERT Models, Multi-Objective Optimization)

Experiments on multi-objective optimization with BERT models.

## Environment Setup
1. If the `FT_Model.zip` file has not been extracted, extract it.
```
unzip ../FT_Model.zip -d ..
```

2. Create a virtual environment
```
python -m venv [envname]
```

3. Activate the virtual environment
```
source [envname]/bin/activate
```

4. Install the required libraries
```
pip install -r requirements.txt
```

5. (Optional) Log in to Hugging Face

Some gated or restricted models may require requesting access on Hugging Face before downloading.

```
huggingface-cli login
```

## Running the Experiment
1. Run the script
```
bash ./optimization.sh
```

## optimization.sh
The following example is intended for a quick functionality check.
For full experiments, increase `--num-trials`.
```
python main.py \
    --optimization Sequential_BitWidth \
    --num-trials 5 \
    --seed-opt 0 \
    --seed-merge 0 \
    --wandb False \
    --wandb-project 'MergeQuant' \
    --result-dir 'results' \
    --figure-dir 'figures' \
    --test-best True \
    --create-graph True \
```
- optimization: Optimization strategy
    - Sequential_BitWidth: Optimizes quantization bit-widths
        - To run this, the file `./config/best_config_seed{args.seed-opt}.yml` is required. This file is generated by running `Sequential_MergeParameter` in `BERT/Constrained_Optimization`. The file must be copied manually to `./config/` directory.
    - Joint: Optimizes merge parameters and quantization bit-widths
- num-trials: Number of Optuna trials
- seed-opt: Random seed for the sampler
- seed-merge: Random seed for model merging
- wandb: Enable logging with Weights & Biases (optional) (`True` or `False`)
- wandb-project: Project name used when logging experiments with Weights & Biases (W&B)
- result-dir: Directory to save results
- figure-dir: Directory to save figures
- test-best: Evaluate the best configuration on the test set
- create-graph: Generate Pareto front plots

## Experimental Results

The raw experimental results and optimization logs are stored in the `result/` directory. Results are organized by optimization strategy and random seed.

For clarity and reproducibility, this repository stores experimental results in a more organized format than the original implementation.
As a result, some saved files may differ slightly from those used during the original experiments.

### Directory Structure
```
result/
├── Joint/
│   ├── seed=0/
│   │   ├── results_seed=0/
│   │   └── figure_seed=0/
│   └── seed=1/
└── Sequential_BitWidth/
    ├── seed=0/
    │   ├── results_seed=0/
    │   └── figure_seed=0/
    └── seed=1/
```
- `results`
    ```
    results/
    ├── study_trials.csv        # All trial results during optimization
    ├── pareto_fronts.csv       # Pareto-optimal solutions (CSV format)
    ├── pareto.json             # Summary of Pareto solutions (train/test scores and bit-widths)
    └── tmetrics_{number}.json  # Task-wise test results for each Pareto solution
    ```

- `figures`
    ```
    figures/
    └── pareto_fronts.png       # Visualization of Pareto-optimal solutions
    ```
