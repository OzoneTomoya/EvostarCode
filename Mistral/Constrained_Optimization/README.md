# Merge Quant (Mistral Models, Constrained Optimization)

Experiments on constrained optimization with Mistral models.

## Environment Setup
1. Create a virtual environment
```
python -m venv [envname]
```

2. Activate the virtual environment
```
source [envname]/bin/activate
```

3. Install the required libraries
```
pip install -r requirements.txt
```

4. Download the language identification model lid.176.ftz from [the link](https://fasttext.cc/docs/en/language-identification.html)
```
wget https://dl.fbaipublicfiles.com/fasttext/supervised-models/lid.176.ftz
```

5. (Optional) Log in to Hugging Face

Some gated or restricted models may require requesting access on Hugging Face before downloading.

```
huggingface-cli login
```

## Running the Experiment
1. Run the script
```
bash ./optimization.sh
```

## optimization.sh
The following example is intended for a quick functionality check.
For full experiments, increase `--num-trials`.
```
python main.py \
    --optimization Sequential_MergeParameter \
    --num-trials 5 \
    --seed-cmaes 0 \
    --seed-merge 0 \
    --wandb False \
    --wandb-project 'MergeQuant' \
    --result-dir 'results' \
    --figure-dir 'figures' \
    --save-interval 100 \
    --test-best True \
    --create-graph True \
    --target-bit 8 \
```
- optimization: Optimization strategy
    - Sequential_MergeParameter: Optimizes merge parameters
    - Sequential_BitWidth: Optimizes quantization bit-widths
        - To run this, the file `./config/best_config_seed{args.seed-opt}.yml` is required. This file is generated by running `Sequential_MergeParameter`.
    - Joint: Optimizes merge parameters and quantization bit-widths
- num-trials: Number of Optuna trials
- seed-cmaes: Random seed for the sampler
- seed-merge: Random seed for model merging
- wandb: Enable experiment logging with Weights & Biases (optional) (`True` or `False`)
- wandb-project: Project name used when logging experiments with Weights & Biases (W&B)
- result-dir: Directory to save results
- figure-dir: Directory to save figures
- save-interval: Interval for saving intermediate results during optimization
- test-best: Evaluate the best configuration on the test set
- create-graph: Generate optimization history plots
- target-bit: Target average bit-width for quantization

## Experimental Results

The raw experimental results and optimization logs are stored in the `result/` directory. Results are organized by optimization strategy and quantization bit-widths.

For clarity and reproducibility, this repository stores experimental results in a more organized format than the original implementation.
As a result, some saved files may differ slightly from those used during the original experiments.

### Directory Structure
```
result/
├── Joint/
│   ├── bit=7/
│   │   ├── results_seed=0/
│   │   └── figure_seed=0/
│   ├── bit=8/
│   │   ├── results_seed=0/
│   │   └── figure_seed=0/
├── Sequential_MergeParameter/
│   ├── bit=7/
│   │   ├── results_seed=0/
│   │   └── figure_seed=0/
│   ├── bit=8/
│   │   ├── results_seed=0/
│   │   └── figure_seed=0/
└── Sequential_BitWidth/
    ├── results_seed=0/
    └── figure_seed=0/
```

- `results`
    ```
    results/
        ├── best_config.yml         # Merge parameters at the point of best performance during optimization
        ├── best_bit.yml            # Quantization bit-width at the point of best performance during optimization
        ├── best_score.json         # Scores using best_config and best_bit
        ├── test_result_best.json   # Model outputs using best_config and best_bit
        ├── test_score_best.json    # Evaluation scores using best_config and best_bit
        ├── study_trials.csv        # Optimization history
        └── trial_{num}.json        # Model outputs at each save interval during optimization (Only trials satisfying constraints are stored)
    ```

- `figures`
    ```
    figures/
    └── optimization.png    # Progression of the best score during optimization
    ```
